# cat-bot

Telegram-бот, который автоматически присылает картинки котов в чат с заданной периодичностью. 
Работает в Kubernetes с CI/CD через Jenkins и мониторингом в Prometheus + Grafana.

## 📌 О проекте

Бот подключается к вашему чату и **каждые 5 секунд** отправляет новую картинку кота. 
Картинки берутся из [TheCatAPI](https://thecatapi.com/) с автоматическим fallback 
на [Cataas](https://cataas.com/). Каждый чат имеет своё независимое состояние: 
можно включать и отключать рассылку в любой момент.

## ✨ Возможности

- 🐱 **Автоматическая рассылка** — новая картинка каждые 5 секунд
- 🎛️ **Управление рассылкой** — включение/остановка на уровне чата
- 🌐 **Два источника картинок** — TheCatAPI + резервный Cataas
- 🚀 **CI/CD** — автоматический деплой через Jenkins
- 📦 **Kubernetes** — развёртывание в K8s с репликацией
- 📊 **Мониторинг** — метрики в Prometheus, дашборды в Grafana
- 🔔 **Алертинг** — уведомления при падении пода

## 🛠️ Технологический стек

| Компонент | Технология |
| :--- | :--- |
| Язык | Node.js (LTS) |
| Framework | Telegraf 4.16 |
| Источник картинок | TheCatAPI (fallback — Cataas) |
| Конфигурация | dotenv |
| Контейнеризация | Docker |
| Оркестрация | Kubernetes (Docker Desktop) |
| CI/CD | Jenkins (Kubernetes-агент) |
| Мониторинг | Prometheus + Grafana |
| Алертинг | Alertmanager → Telegram |
| IaC | Ansible |
